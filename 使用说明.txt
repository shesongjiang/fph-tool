FPH 仪表设置工具 使用说明
================================
适用仪器：Rohde & Schwarz Spectrum Rider FPH（已验证 1321.1111K13 / FW V2.10）
连接方式：网线直连或同网段，SCPI over VXI-11（纯 Python 后端，无需安装 VISA 驱动）

一、连接
  1. 资源串默认 TCPIP::192.168.29.2::INSTR，可按实际 IP 修改。
  2. 点「连接」：读取 *IDN? 确认仪表，并自动保存当前设置的快照。
  3. 「断开」退出；「恢复连接时设置」一键回滚到连接时的仪表状态。

二、参数设置（左侧面板，全部为真机验证过的 SCPI）
  - 频率：中心频率 / Span（MHz）。
  - 扫描时间：可自动或手动（秒）。手动值不能小于 RBW 决定的物理最短
    扫描时间，过小会被仪表拒绝/自动调整；空值=沿用仪表当前值。
  - RBW / VBW：可自动或手动（kHz，先关 AUTO 再写值）。
  - 参考电平 / 输入衰减：默认 RLEV=0 / ATT=15dB（13dB 外部衰减器场景的安全值）。
    功率档 0 时仪表入口约 -4dBm，ATT=0/RLEV=-10 会触发中频过载(IFOVL)！
    注意两者耦合，被拒时工具会自动改开自动衰减并重试。
  - 触发源：IMM（本固件不支持 VID 视频触发）。
  - 迹线方式（会下发到仪表，回读校验）：
      单扫     —— DISP:TRAC:MODE WRITE。单次扫描。突发发包信号只抓到随机碎片（梳状尖峰）。
      峰值保持 —— DISP:TRAC:MODE MAXH。仪表硬件峰值保持铺出包络，工具再连续读 N 次
                 逐点取最大。**看发包信号请用这个**，读数是包络功率上限，非平均功率。
      软件平均 —— DISP:TRAC:MODE AVER。**只适合连续/稳态信号**；
                 对突发发包信号会把读数抹低几十 dB（信号特性，非仪表故障）。
  - 「应用全部参数」：按 触发→带宽→衰减→参考电平→Span→中心频率→迹线方式→
    扫描时间→平均次数 的可靠顺序逐条下发，每条都回读校验并查 SYST:ERR。
  - 「2.4G 信道一键预设」：选 1~14 信道，一键把中心频率设到该信道。
  - 「填入 TX 测试默认值」：Span40M / RBW100k / VBW300k / RLEV0 / ATT15 /
    峰值保持x8 / 扫描时间自动，与 tx_autotest_config.json 的 per_channel 一致。

三、测量辅助
  - 外部衰减（默认 13 dB）：DUT 到仪表入口的固定衰减器/线缆损耗，
    读数 +该值 换算成 DUT 天线口功率。
  - 信道带宽（默认 20 MHz）：用于带内积分功率（信道功率）计算。
  - 过载预警：峰值接近参考电平 3dB 以内时，信息栏和日志会提示加大衰减。
  - DUT 是突发发包（set_tx 末尾 10000 疑为包间隔 us，占空比仅数%），
    set_tx 返回 done 后射频有约 3 秒启动延迟——发完命令等 3~5 秒再读。

四、迹线显示（右侧面板）
  - 「读取迹线」：读 711 点 TRACE1 并绘制曲线，显示峰值标记、中心频率参考线。
    信息栏显示：峰值 dBm@频率 | 信道功率 dBm | DUT 口功率 dBm（含外部衰减补偿）。
  - 「自动刷新」：按设定间隔连续读取。
  - 「保存 CSV」：index / freq_hz / freq_mhz / power_dbm 四列。

五、日志
  底部通信日志带时间戳和颜色分类，可保存/清空。

六、已知限制
  - FPH 为标量频谱仪，无解调能力（EVM 等需矢量信号分析仪）。
  - TRAC:DATA? TRACE1 固定 711 点；40MHz span 的频率分辨率约 56.6 kHz/bin，
    需要更细的频率观测时把 Span 收窄（如 5MHz -> 7kHz/bin）。
  - 视频触发 VID 会被固件拒绝（-221），触发源请用 IMM/EXT。
  - 2.4G 信道频率 = 2407 + 5×信道号（ch1=2412, ch11=2462, ch14=2472）。
